# 被持仓 ETF 的深度分析加跑清单

用户问"详细分析589720"这类问题时，如果该 ETF 在他的网格账本里有持仓，
纯估值报告是废纸——他是网格交易者，要的是"这个环境对我的网格意味着什么"。

## 1. 先读账本，不要问用户

```python
import confirmed_runtime as r
root = r.root_from_home()          # → hermes-home/cache/grid-account
st = r.load_states(root)           # keys: 'sh589720' / 'sz159363' / 'sz159992'
pos = st['sh589720']
```

先 `for k, v in pos.items()` 打印字段名确认（不同 ETF 可能略有差异），再用这些字段：

| 字段 | 用途 |
|------|------|
| `qty` / `sellable_qty` | 持仓/可卖（差值是当日 T+0 买入） |
| `max_grid` | 最大格号——已到 H 说明格子接近设计上限 |
| `net_invested` / `net_unit_cost` | 净投入与加权单位成本，算浮亏 |
| `remaining_unit_cost` | 剩余未平仓成本（比总成本更反映当前风险） |
| `open_grid_positions` | 每格在持买入价（含 lot/id/price/qty/date） |
| `t_records` / `t_net` | 做T 完成轮次与净利 |

**坑**：`load_states()` 必须传 `root`（签名 `load_states(root)`），
且入口是 `root_from_home()` 不是模块级常量；`load_state`（单数）不存在。

## 2. 必算的三个画像

1. **浮亏**：现价 vs `net_unit_cost`（如 0.772 vs 0.8027 → -3.8%）。
2. **格子分布**：列出每格买入价。若**每一格都高于现价**，说明是下跌接力接上来的，
   不是选错标的；若最大格号已接近设计档数，说明**子弹将尽**（再跌只能停买）。
3. **做T 战绩**：`t_net` 是已验证的净差价收入（如 1189.20 元/9 轮），
   这是网格策略真实贡献的证据，比浮亏更能说明策略是否在工作。

## 3. 交叉引用市况标签

跑 `python tools/market_phase_check.py`（见本 skill 的决策树）拿该标的 ADX/量能/操作信号。
**关键洞察**：单只 ETF 的 ADX 可能与大市指数完全不同步——
如 2026-10-23：大盘指数 ADX 36-48 单边下跌给"空仓观望"，
而 589720 自身 ADX=17 已转震荡 + 量能缩到峰值 23%，给"网格波段·5成"。
必须分别陈述，不能用一个结论覆盖两个层面。

## 4. 组合重叠敞口（最容易被忽略的风险）

用户同时持有多只同方向 ETF：589720 科创创新药 + 159992 创新药（迁移退出中）。
分析单只时必须提示：**真实赛道敞口 = 各只持仓市值之和**，
比他看单只 589720 的浮亏大得多。159992 是 active=false 只卖不买，
但仍是真实持仓，不能从风险画像里排除。

## 5. 分层给结论，不越界

- **工具层**：同类比较（规模/流动性/费率）→ 该 ETF 是不是好工具。
  例：589720 vs 589120（同指数），成交额 6.57 亿 vs 1.49 亿，国泰流动性碾压。
- **环境层**：ADX/量能/回撤位置 → 现在适不适合跑网格。
- **执行层**：具体挂单价/接回价 → **归 09:20 盘前条件建议**，深度分析报告不代下单、
  不设计网格参数（那是 etf-grid-research / 回测引擎的职责）。

## 6. 数据缺口诚实披露

AkShare 实时接口（`fund_etf_spot_em` / `fund_etf_fund_info_em`）本环境常被限流
或 "Length mismatch: Expected axis has 14 elements, new values have 13 elements" 报错；
指数成分/PE/加权ROE 也常取不到。按铁律标 `数据缺失`，
改用可验证的替代锚：距历史高低点、量能比值、ADX、账本真实成本。
**不要用估值类字段编数。**

## 7. 同类 ETF 比较的取数捷径

同指数的竞品规模常搜不到，但**成交额是最硬的规模代理**：
直接拉两只 ETF 的日K对比近 20 日均额（589720 6.57亿 vs 589120 1.49亿 → 4.4倍），
比搜"XX ETF 规模多少亿"可靠且快。费率从天天基金档案页/新闻搜索交叉验证。

# 两轴分析框架（用户 2026-10-27 定调）

用户原话：“对于我而言，更关心的是分红以及股价的上涨。你的所有分析都应该是围绕这两个方向。”后续用美的 2021 案例再次强化（108 元买入五年含息回报≈0，ROE 高但买贵了照样白拿）。

## 铁律

1. **一切个股分析只围绕两轴展开**：
   - 分红轴：股息率（TTM 实拉）→ 明年到手多少、会不会更多（净利趋势+派息率空间）、什么情况断息
   - 股价轴：位置（52周分位/均线）→ 买点/卖点/止损具体价位、催化剂
2. **ROE 等中间指标禁止单独出现/吹嘘**，只作定价工具，以“盈利收益率 = ROE÷PB = EPS÷现价 = 1÷PE”形态出现。四个恒等式可互换，选用户熟悉的入口讲。
3. **买入理由 = 便宜（盈利收益率够高）+ 趋势止跌**；分红只是拿得住的理由，不是买入的理由。
4. 悲观场景必须量化（具体亏损%），止损线要给出数学含义（如破位价与悲观场景的差额 = 纪律省下的钱）。

## 推荐结构（每次个股推荐照此交付）

- 分红轴：股息率 / 派息率（提升空间）/ 净利 YoY（水源）
- 股价轴：52周价格分位 / PE 历史分位 / 趋势（多空震）/ 年线位置
- 操作：买入区间、止损价、目标价，全部具体数字
- 退出线（论点破坏者）：如银行股不良率/拨备阈值、分红率>100%、连续两季净利负增长

## 两把分位尺（别混用）

| 尺 | 算法 | 回答 |
|---|---|---|
| 52周价格分位 | (现价−52周最低)/(最高−最低) | 股价贵不贵（站在这年山头什么位置） |
| PE 历史分位 | 当前PE_TTM 在近5年每日PE序列中的百分位 | 估值贵不贵 |

两尺同向低价位（如平安 25%+2.4%）才是强信号；单尺低分位≠可买（中联重科 4% 价格分位但净利 -24% 红旗）。

## 排序门槛（批量筛选用，透明无黑箱）

- A 级：股息率≥4.5% 且 盈利收益率≥7% 且 趋势非空头
- 红旗🚩：派息率>100%（分本金）或 净利 YoY<-20%（水源枯竭）→ 一律回避
- 高分位（PE 分位>90%，如工行/建行/中国建筑 100%）即使 A 级也要降级为“等回调”

# PE 历史分位取数（东财接口，实测可用）

westock 无个股历史 PE 序列，用东财 datacenter API（2026-10-27 实测 48 只全通过）：

```
https://datacenter-web.eastmoney.com/api/data/v1/get?reportName=RPT_VALUEANALYSIS_DET&columns=TRADE_DATE,PE_TTM,PB_MRQ&filter=(SECURITY_CODE%3D%22601318%22)&pageSize=500&pageNo=1&sortColumns=TRADE_DATE&sortTypes=-1
```

- 返回全历史每日 PE_TTM/PB_MRQ（平安 PE 5.98 与 westock 计算吻合，可交叉验证）
- 翻页：`result.pages` 控制，pageSize=500，每页间隔 ~0.4s 防限流
- 分位：近5年窗口（≥200 交易日）内 `sum(pe<=当前)/n`
- 已固化脚本：`D:/Code/AH_analyse/tools/divi_pe_pctile.py`（48只×2500日实测约3分钟）

## 低基数陷阱（净利 YoY 必查基数）

五粮液 2026 中报净利 +89.3% 是真的，但源于 2025 同期基数重述下调 76%（“改财报”），同期产销腰斩、销售费用 +80%、经营现金流为负——**数字真、质量假**。

净利 YoY>+50% 时必须查：①上年基数是否被重述/异常低；②产销量、现金流、费用是否同向恶化。低基数虚增一律按红旗处理。

## 本轮结论存档（2026-10-27，48只三榜扫描）

- 唯一“价格分位低+PE分位历史最低区+净利增长+派息率有空间+趋势企稳”五项全占：中国平安（52.5 元，PE分位 2.4%）
- 保险三兄弟霸榜便宜区：太保 1.6% / 人寿 2.0% / 平安 2.4%（PE 5年分位）
- 高息明星估值水位全在顶部：工行/建行/中国建筑 100%、神华 93.6%、格力 93.8%——“高息板块估值修复到拥挤”是本轮主基调，追高=接最后一棒概率高
- 农行 82.8% 分位降级为“等回调”；成都银行 78.8% 分位支持“等 18 元以下”纪律

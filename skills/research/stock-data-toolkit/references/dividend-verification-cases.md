# 股息率验证实战案例（2026-10-27，三表核验）

用户给了三张来源不同的股息榜单截图，要求合并去重、逐只实据验证、重排名。结论与教训全部可复用。

## 三张表的口径与可信度

| 来源 | 口径 | 判定 |
|---|---|---|
| App“股息率前20名” | 不明（疑似夸大/旧价分母） | ❌ 中远海控 10.37% vs 实际 TTM 5.24%，虚高一倍 |
| 财知合一社“股息率金字塔”(9月) | 混合（多数单财年） | ⚠️ 多数准（±0.5pp），神华 4.1% 偏低（未含中期分红） |
| 雨笠攒股日记“20只精选”(10-26) | 单财年，内部自洽 | ✅ 19/19 行 DPS÷股价与表内股息率吻合到小数点后两位；但银行单财年口径系统性低估（工行 3.61% vs TTM 5.36%） |

**方法论**：榜单可信度 = 内部一致性（逐行算 DPS÷价格 对不对） × 口径披露。内部一致但口径陈旧 → 数字“真”但会误导；内外都不一致 → 编数。

## 代表性个股的口径差（同一只票四源四数）

中国神华：App 7.70% / 金字塔 4.1% / 雨笠表 4.51% / 本机 TTM 5.99%（近365天3次除息：0.98+1.03+0.98）。

## 陷阱实例（重排名时净利YoY交叉验证的成果）

- 浙能电力 5.79% 但净利 -57% → 分母跌出来的股息，不可持续
- 中国建筑 5.91% 但净利 -24%；中国中铁 -27% → 基建链盈利崩塌，高息是“最后一年的”
- 华夏银行 6.58% 但净利 -18.4% + ROE 6.3% → App 榜第9纯属误导
- 中远海控 App 榜榜首 10.37%，真实 TTM 5.24%，2024-25 海运暴利期高派息 + 股价腰斩的周期顶陷阱
- 格力电器 8.17% 全场最高但净利 -7.9% + 技术面空头 → “高息是黄金坑还是价值陷阱”需正面单查，不能只看股息率
- 成都银行 TTM 7.43% 榜首，但含中期分红首年的窗口效应，可持续口径约 5.3%（EPS×派息率验证）

## 正面发现（TTM 口径下被低估的）

- 工商银行：单财年 3.61% → TTM 5.36%（3次派息），雨笠表低估 1.75pp
- 中国平安：净利 +36.1%、ROE 15.5%、股息 5.2%，三表都没强调的基本面反转标的

## 综合排名公式（可复用）

综合分 = 0.45×股息分 + 0.35×基本面分 + 0.20×技术面分
- 股息分：6% 满分、3% 及格的线性映射
- 基本面分：净利YoY（±20 分）+ ROE（（ROE-8）×2，±20）
- 技术面分：均线排列/MACD/RSI/KDJ 加减分，超卖加分超买减分
结果前三：中国神华 81.0、成都银行 80.5、美的集团 74.8（2026-10-27）。

## 流程教训

1. 交付前先看图把名单读全（长图 vision 提取可能截断，多问几次指定段落）；截断段必须显式标注“未读到”，不许用推测补名单。
2. 批量采集先落脚本再跑（48只零失败）；脚本静默丢票 = 事故，必须失败清单上 stderr。
3. 用户要的“验证+分析+重排”是三层交付：口径判定 → 实据数字 → 陷阱标注，缺一不可。

# 网格状态回归场景

## 场景 A：三格持仓

159992：A 0.871、B 0.863、C 0.846，三格均 T+1 可卖。默认卖 C，目标 0.863；不能默认卖 A 0.888。

## 场景 B：C 成交后的正常挂单

C 买入已确认后，操作单应同时包含：

- C 卖出：C 实际成交价 × 1.02；
- D 买入：C 实际成交价 ÷ 1.02，按预算取整百；

D 价格尚未触发不影响 D 作为 resting limit order 提前挂出。

## 场景 C：部分成交

票据包含 159992 卖 C、159992 买 D、159363 卖 B、159363 买 D。若只确认 159363 买 D 5100 份、实际 1.169：

- 只增加 159363 D lot；
- 卖出目标按实际价计算为 1.192；
- 可卖日为下一交易日；
- 其余动作继续 pending；
- 不把限价 1.174 当实际成交价；
- 不把同票据其他动作记为成交。

## 场景 D：连续穿格提醒

若上次价为 0.850，本次价为 0.820，且 pending 买格为 0.829、0.812：仅对区间内实际穿越的格子提醒一次。提醒必须写“请核对券商是否成交”，不能直接入账。

## 场景 E：T+1 池卖单排序（589720）

589720 持仓：A 9200@0.877（卖 0.895，T+1）、B 9400@0.859（卖 0.876，T+1）、C 9600@0.829（卖 0.846，**今日买入 T+0**）。总 T+1 池 = 18600。

- `next_sell_lot()` 按 sell 升序选最低 → **C 格 0.846**。
- C 格本身今日不可卖，但其卖价可以用 A+B 的 T+1 库存挂单，池 18600 ≥ 9600，**可挂**。
- **禁止**在 `next_sell_lot` 内按 `available_from` 过滤——那会隐藏最低卖价，迫使系统选 B 格 0.876 而不是 C 格 0.846。
- 外层用 `available(pos, d)` 校验池覆盖即可，不需要选中的 lot 本身可卖。

## 禁止回归

- 用 `max(sell)` 选远端卖格；
- 以“当前价未到买价”为理由不挂下一格；
- 将挂单或穿价当成交；
- 对多动作票据用一次“成功”把全部动作入账；
- 当日买入 lot 当日卖出；
- 重新生成时重复挂同一委托。

# 成本与结构效率指南

## 一、ETF 交易成本全景

### 1.1 显性成本

| 成本项 | A股ETF | 港股ETF | 美股ETF | QDII ETF(A股上市) |
|--------|--------|---------|---------|-----------------|
| 买入佣金 | 万2-万5 | 万5-千3 | $0（多数券商） | 万2-万5 |
| 卖出佣金 | 万2-万5 | 万5-千3 | $0 | 万2-万5 |
| 印花税(卖出) | 0.05% | 0.13%（买卖双向） | 0 | 0.05% |
| 过户费 | 0.001% | — | — | 0.001% |
| 最低佣金 | 5元 | 50-100港元 | $0 | 5元 |

### 1.2 隐性成本

| 成本项 | 说明 | 量级 |
|--------|------|------|
| **买卖价差** | Bid-Ask Spread | 0.02%-0.5%/次 |
| **市场冲击成本** | 大额交易推升/打压价格 | 视成交额而定 |
| **管理费+托管费** | 每日计提 | 0.15%-1.5%/年 |
| **指数使用费** | 含在管理费中 | — |
| **现金拖累** | 基金持现不产生指数收益 | 0-0.3%/年 |
| **展期成本** | 商品期货ETF特有 | 0-10%/年 |

### 1.3 总持有成本（TCO）估算模型

```
年化总持有成本 ≈ 管理费 + 托管费 + (买卖价差 × 换手次数) + 跟踪误差中的费用部分
```

**示例**：
- 沪深300ETF（510300）：0.15%管理 + 0.05%托管 = **0.20%/年**
- 纳指QDII ETF（513100）：0.50%管理 + 0.10%托管 = **0.60%/年**
- 黄金ETF（518880）：0.40%管理 + 0.08%托管 = **0.48%/年**

## 三、跨境结构风险

### 3.1 QDII 额度风险

**核心机制**：
- QDII ETF 需要使用外汇额度购买境外资产
- 额度由外管局审批，各基金公司额度有限
- 额度用完 → 暂停申购 → 场内供给不增加 → 溢价飙升

**溢价风险传导链**：
```
QDII额度用完 → 暂停申购 → 场内ETF供给固定
     ↓
市场买入需求 > 供给 → 场内价格 > 基金净值 → 产生溢价
     ↓
溢价率越高 → 买入的人亏损概率越大（溢价终会收窄）
```

**溢价率判断标准**：

| 溢价率 | 风险等级 | 建议 |
|--------|---------|------|
| <2% | 正常 | 可正常买入 |
| 2-5% | 偏高 | 谨慎，关注额度恢复消息 |
| 5-10% | 高 | 不建议买入 |
| >10% | 🔴 极高 | **一票否决**，买入即亏 |

### 3.2 汇率风险量化

**影响公式**：
```
QDII ETF 人民币收益 = 底层资产本币收益 + 汇率变动收益
```

**近5年人民币/美元波动**：
- 年化波动率约 3-5%
- 极端情况单年波动可达 8-10%

**对冲选择**：
- 部分 QDII ETF 提供汇率对冲版本（如人民币对冲份额），但对冲成本约0.5-1%/年
- 多数投资者选择不对冲（长期汇率均值回归假设）

### 3.3 时差风险

| QDII方向 | 净值延迟 | 影响 |
|---------|---------|------|
| 美股 | T+1（次日公布净值） | 交易日盘中不知真实净值 |
| 欧股 | T+1 | 同上 |
| 港股 | T+0（收盘后即可知） | 影响较小 |

### 3.4 清盘与合并风险

**清盘触发条件**（任一即可能触发）：
- 基金资产净值连续60个工作日<5000万元
- 基金份额持有人<200人
- 基金合同约定的其他条件

**清盘对投资者影响**：
- 按最后一日净值清算，不一定亏钱
- 但被动退出 → 可能错过后续反弹
- 清盘过程需1-3个月

## 四、折溢价监测

### 4.1 折溢价计算

```
折溢价率 = (场内价格 - 基金净值) / 基金净值 × 100%
```

- **溢价** > 0%：场内价格高于净值，买入不划算
- **折价** < 0%：场内价格低于净值，理论上买入划算

### 4.2 各类ETF折溢价正常范围

| ETF类型 | 正常范围 | 异常警戒 |
|---------|---------|---------|
| A股宽基ETF | ±0.1% | >0.5% |
| A股行业ETF | ±0.2% | >1% |
| 港股通ETF | ±0.3% | >1.5% |
| QDII ETF | ±1% | >5% |
| 商品ETF | ±0.2% | >1% |

### 4.3 长期溢价的原因

1. **QDII额度限制**：最常见原因，需等待额度恢复
2. **做市商不足**：缺乏套利机制
3. **市场情绪过热**：短期资金涌入
4. **信息不对称**：净值公布延迟导致定价偏差

## 五、商品 ETF 特有成本

### 5.1 展期成本（Roll Cost）

**适用于**：通过商品期货跟踪的ETF（如原油ETF、豆粕ETF）

**机制**：
- 期货合约有到期日，ETF 需定期将近月合约移仓至远月
- **Contango（正向市场）**：远月>近月 → 展期亏钱（卖低买高）
- **Backwardation（反向市场）**：远月<近月 → 展期赚钱（卖高买低）

**展期成本估算**：

| 市场结构 | 年化展期影响 | 典型标的 |
|---------|------------|---------|
| 强Contango | -5%~-15% | 原油（多数时间） |
| 弱Contango | -1%~-5% | 工业金属 |
| Flat | ~0% | — |
| Backwardation | +1%~+5% | 偶尔出现 |

**黄金ETF例外**：
- 黄金ETF通常持有实物黄金或伦敦金现，无展期成本
- 这是黄金ETF优于原油ETF的重要原因之一

### 5.2 仓储成本

| 商品 | 是否有仓储成本 | 说明 |
|------|-------------|------|
| 黄金 | 极低 | 体积小、不损耗 |
| 原油 | 高 | 储罐租赁费 |
| 农产品 | 中高 | 有损耗 |

## 六、成本与结构效率评分细则

### 评分表（模块六总分100分）

| 子项 | 分值 | 评分依据 |
|------|------|---------|
| 交易成本 | 25分 | 佣金+印花税+价差的综合水平 |
| 持有成本 | 25分 | 管理费+托管费+展期（如适用） |
| 税务效率 | 25分 | 分红税率+持有期限优化空间 |
| 结构风险 | 25分 | 折溢价+清盘风险+汇率风险+额度风险 |

### 简化评分（宽基/行业ETF模式）

对于不涉及跨境的 A 股宽基/行业 ETF，成本维度权重为0%，但仍需在报告中列出：
- 费率是否为同类最优
- 是否存在更低费率的替代品
- 长期持有的税务优化建议

### QDII/商品 ETF 重点检查项

- [ ] 当前溢价率是否在合理范围（<2%）？
- [ ] QDII 额度是否正常（非暂停申购状态）？
- [ ] 汇率风险是否已纳入收益预期？
- [ ] 商品ETF是否有展期成本（期货型）？
- [ ] 清盘风险是否存在（规模<2亿）？

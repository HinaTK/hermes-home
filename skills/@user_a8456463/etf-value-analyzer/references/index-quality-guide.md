# 指数质量评估指南

## 一、指数编制规则评估

### 1.1 选样方法论

| 方法 | 说明 | 质量评级 |
|------|------|---------|
| **市值加权** | 按自由流通市值加权，大公司权重高 | ⭐⭐⭐ 经典可靠 |
| **等权重** | 每只成分股等比例，定期再平衡 | ⭐⭐⭐ 避免过度集中 |
| **基本面加权** | 按营收/利润/股息/净资产加权 | ⭐⭐⭐ 价值导向 |
| **策略加权** | Smart Beta策略（低波动/动量/红利等） | ⭐⭐ 有历史验证但可能过拟合 |
| **主观选样** | 委员会主观判断 | ⭐ 透明度低 |

### 1.2 调样机制评估

**好的调样机制**：
- 调样频率明确（半年/季度）
- 调入调出规则量化且公开
- 有缓冲区设计（避免频繁进出）
- 调样预公告制度

**差的调样机制**：
- 调样频率不规则
- 选样标准模糊
- 人为干预成分明显
- 无预公告，突然调整

### 1.3 核心指数编制规则参考

| 指数 | 编制机构 | 选样数量 | 加权方式 | 调样频率 |
|------|---------|---------|---------|---------|
| 沪深300 | 中证指数公司 | 300只 | 自由流通市值加权 | 半年 |
| 中证500 | 中证指数公司 | 500只 | 自由流通市值加权 | 半年 |
| 创业板指 | 深圳证券信息 | 100只 | 自由流通市值加权 | 季度 |
| 恒生指数 | 恒生指数公司 | ~80只 | 自由流通市值加权（上限10%） | 季度 |
| 标普500 | S&P Dow Jones | 500只 | 自由流通市值加权 | 按需 |
| 纳斯达克100 | Nasdaq | 100只 | 修正市值加权（上限24%） | 季度+年度 |

## 二、成分股质量评估框架

### 2.1 集中度分析

**HHI 指数（赫芬达尔指数）计算**：
```
HHI = Σ (各成分股权重%)²
```

| HHI 值 | 集中度 | 评价 |
|--------|--------|------|
| <500 | 极度分散 | 风险分散良好 |
| 500-1000 | 较分散 | 良好 |
| 1000-2000 | 适度集中 | 可接受 |
| 2000-4000 | 较集中 | 需注意 |
| >4000 | 高度集中 | 单一股票风险高 |

### 2.2 前N大权重分析

| 指标 | 计算方式 | 健康阈值 |
|------|---------|---------|
| CR3（前3大） | 前3只权重之和 | <30% 为佳 |
| CR5（前5大） | 前5只权重之和 | <40% 为佳 |
| CR10（前10大） | 前10只权重之和 | <60% 为佳 |
| 最大单只权重 | 第1大成分股权重 | <15% 为佳 |

**注意**：行业ETF因跟踪行业指数，集中度天然较高，需放宽标准。

### 2.3 成分股基本面质量

**整体指标（取成分股加权中位数/均值）**：

| 指标 | 优秀 | 良好 | 一般 | 差 |
|------|------|------|------|---|
| 加权ROE | >15% | 10-15% | 5-10% | <5% |
| 加权净利润增速 | >15% | 8-15% | 0-8% | <0% |
| 盈利公司占比 | >90% | 80-90% | 60-80% | <60% |
| 加权股息率 | >3% | 2-3% | 1-2% | <1% |

### 2.4 行业分布分析

**评估要点**：
- 行业分布是否与跟踪指数设计目标一致
- 是否过度暴露于单一行业（宽基不应单行业>30%）
- 是否覆盖经济体核心增长行业
- 新兴行业 vs 传统行业占比是否合理

## 三、指数长期表现评估

### 3.1 收益指标

| 指标 | 计算方式 | 评估标准 |
|------|---------|---------|
| 年化收益（5年） | CAGR | >10% 优秀（A股/美股） |
| 年化收益（10年） | CAGR | >8% 优秀 |
| 累计收益 vs 通胀 | 实际收益率 | 必须跑赢通胀 |
| 全收益 vs 价格指数差 | 含分红收益 | 差距越大说明分红贡献越大 |

### 3.2 风险指标

| 指标 | 计算方式 | 评估标准 |
|------|---------|---------|
| 年化波动率 | 日收益率标准差×√250 | <20% 低波动 / 20-30% 中等 / >30% 高波动 |
| 最大回撤 | 峰值到谷底最大跌幅 | <-30% 可控 / -30%~-50% 高 / >-50% 极高 |
| 回撤恢复时间 | 从最大回撤恢复至前高所需月数 | <12月好 / 12-24月中等 / >24月差 |
| 负收益年份占比 | 近10年中负收益年份数/10 | <30% 好 |

### 3.3 风险调整收益

| 指标 | 公式 | 评估标准 |
|------|------|---------|
| 夏普比率 | (年化收益-无风险)/年化波动率 | >1.0 优秀 / 0.5-1.0 良好 / <0.5 一般 |
| 卡玛比率 | 年化收益/最大回撤绝对值 | >0.5 优秀 / 0.3-0.5 良好 / <0.3 一般 |
| 索提诺比率 | (年化收益-MAR)/下行标准差 | >1.5 优秀 / 1.0-1.5 良好 / <1.0 一般 |

## 六、🆕 v2.0 巴菲特补丁：指数级护城河评估

> **完整方法论见 `buffett-lens.md`**。本节为快速对照表。

### 6.1 护城河类型与强度速查

| 类型 | 强度 | 典型代表 | 评估要点 |
|------|------|---------|---------|
| 国家级 | ⭐⭐⭐⭐⭐ | 标普500/沪深300/MSCI全球 | 跟踪一国GDP的整体盈利 |
| 垄断格局 | ⭐⭐⭐⭐ | 中证白酒/必需消费 | 行业有壁垒+寡头格局 |
| 结构性增长 | ⭐⭐⭐⭐ | 纳斯达克100/医药 | 长期不可逆趋势支撑 |
| 周期型 | ⭐⭐⭐ | 银行/地产/能源 | 周期不灭但需价格安全垫 |
| 成长但脆弱 | ⭐⭐ | 半导体/新能源 | 技术替代风险，需严控价格 |
| 故事型/概念型 | ⭐ | 元宇宙/Web3/AIGC | 通常是高估泡沫 |

### 6.2 护城河评分（40分，模块一新核心）

| 评估项 | 优秀（30-40） | 良好（20-29） | 一般（10-19） | 差（0-9） |
|--------|---------------|-------------|-------------|---------|
| 经济体/行业的长期不可替代性 | 国家级 | 行业级寡头 | 周期性但有刚需 | 概念/热点驱动 |
| 10年后还会存在并赚钱吗？ | 几乎确定 | 高概率 | 不确定 | 大概率不存在 |
| 商业模式的耐久性 | 数十年验证 | 5-10年验证 | 2-5年验证 | <2年 |
| 自我修复机制 | 自动剔除衰退股 | 定期调样 | 偶尔调样 | 几乎不调样 |

## 七、🆕 v2.0 巴菲特补丁：价值陷阱识别（必查）

> 巴菲特原则："**便宜的烂资产 = 价值陷阱**"。模块二评估时必查。

### 7.1 价值陷阱六大红旗

| # | 红旗 | 解释 | 典型案例 |
|---|------|------|---------|
| 1 | 行业长期 ROE 持续下行 | 10年从15%降至5% | 传统钢铁、煤炭 |
| 2 | 行业营收5年复合负增长 | 永续萎缩 | 传统媒体、固定电话 |
| 3 | 高股息靠"清算式分红" | 不再投入再生产 | 部分老经济央企 |
| 4 | 技术替代风险高 | 颠覆性技术涌现 | 燃油车ETF、传统零售 |
| 5 | PE分位低但PB分位极高 | 利润崩塌中 | 行业景气顶部后期 |
| 6 | 核心成分股退市/重组频繁 | 结构性问题 | 部分港股老经济ETF |

### 7.2 红旗判定与扣分

| 红旗数 | 评分（25满分） | 状态 |
|--------|--------------|------|
| 0 | 22-25 | 健康 |
| 1 | 15-21 | 可接受 |
| 2 | 8-14 | 警惕 |
| ≥3 | 0-7 | **B4 一票否决**触发 → 不推荐 |

### 7.3 区分"周期性低估"与"价值陷阱"

| 维度 | 周期性低估（可买） | 价值陷阱（避开） |
|------|------------------|---------------|
| ROE 趋势 | 周期波动但中枢稳定 | 长期单边下行 |
| 营收 | 周期波动但长期持平/微涨 | 长期负增长 |
| 行业地位 | 龙头格局稳定 | 龙头被颠覆 |
| 技术替代 | 无明显威胁 | 存在颠覆性技术 |
| 典型案例 | 银行ETF（利率底部） | 燃油车ETF（电动化替代） |

## 八、🆕 v2.0 巴菲特补丁：宽基指数的"国运"评估

> 标普500能跑出年化10% 90年，本质是因为它跟踪的是"美国国运"。沪深300能否复制，取决于"中国国运"。

### 8.1 国家级护城河四要素

| 要素 | 优秀 | 一般 | 差 |
|------|------|------|---|
| 人口/劳动力 | 增长或老龄化温和 | 老龄化加速 | 人口断崖 |
| 经济体量 | 全球前5+持续增长 | 全球前20 | 边缘经济体 |
| 产业升级路径 | 清晰且已验证 | 转型中 | 路径不明 |
| 政策稳定性 | 长期可预期 | 周期性变化 | 频繁大变 |

### 8.2 全球主要宽基ETF的"国运"评估（参考）

| 指数 | 国运评估 | 长期年化（参考） | 巴菲特态度 |
|------|---------|----------------|----------|
| 标普500 | ⭐⭐⭐⭐⭐ 美国国运强 | ~10% | 首选 |
| MSCI全球 | ⭐⭐⭐⭐⭐ 全球分散 | ~8% | 推荐 |
| 沪深300 | ⭐⭐⭐⭐ 中国国运 | ~7-9%（待验证） | 中国版标普 |
| 恒生指数 | ⭐⭐⭐ 香港离岸地位 | 较弱（近年） | 谨慎 |
| 日经225 | ⭐⭐⭐ 日本结构性问题 | 1990年代滞涨30年 | 警惕 |
| 印度Nifty50 | ⭐⭐⭐⭐ 人口红利+增长 | ~12%（近10年） | 关注 |
| MSCI俄罗斯 | ⭐ 地缘风险极高 | 高波动 | 远离 |

> 巴菲特的偏好排序：标普500 > MSCI全球 > 其他单一国家。

# ETF 运营质量评估标准

## 一、跟踪误差评估

### 1.1 定义与计算

**跟踪偏离（Tracking Difference）**：ETF 实际收益 - 标的指数收益（单期）

**跟踪误差（Tracking Error）**：跟踪偏离的标准差（衡量偏离的稳定性）

```
年化跟踪误差 = 日跟踪偏离的标准差 × √250
```

### 1.2 评判标准

| 年化跟踪误差 | 评级 | 说明 | 得分(30分制) |
|-------------|------|------|------------|
| <0.3% | S级 | 顶尖水平，通常为超大规模ETF | 28-30 |
| 0.3-0.5% | A级 | 优秀，适合长期持有 | 24-27 |
| 0.5-0.8% | B级 | 良好，可接受 | 18-23 |
| 0.8-1.2% | C级 | 一般，需关注原因 | 12-17 |
| 1.2-2.0% | D级 | 较差，考虑替代品 | 6-11 |
| >2.0% | F级 | 🔴 一票否决警戒线 | 0-5 |

### 1.3 跟踪误差的来源

| 来源 | 影响方向 | 可控性 |
|------|---------|--------|
| 管理费/托管费 | 负向（必然拖累） | 低（固定成本） |
| 成分股调整滑点 | 正负均可 | 中 |
| 大额申赎冲击 | 负向为主 | 中（规模越大越稳） |
| 现金拖累 | 负向 | 中（基金经理能力） |
| 分红再投资时滞 | 负向 | 中 |
| 抽样复制误差 | 正负均可 | 低 |

### 1.4 特殊情况

- **增强型ETF**：主动偏离是设计目标，跟踪误差标准放宽
- **商品ETF**：跟踪现货 vs 期货本身有基差，标准不同
- **QDII ETF**：汇率波动导致跟踪误差天然偏大，标准放宽至1.5%

## 二、费率评估

### 2.1 费率构成

| 费用类型 | 说明 | 频率 |
|---------|------|------|
| **管理费** | 基金公司收取 | 年化，每日计提 |
| **托管费** | 托管银行收取 | 年化，每日计提 |
| **指数使用费** | 支付给指数公司 | 包含在管理费中 |
| **交易佣金** | 调仓时的交易成本 | 不固定 |
| **印花税** | 调仓卖出时 | 不固定 |

**总费率（TER）= 管理费 + 托管费**（投资者最关注的指标）

### 2.2 费率对比基准

| ETF类型 | 极低 | 低 | 中等 | 偏高 | 高 |
|---------|------|---|------|------|---|
| 宽基指数(A股) | <0.2% | 0.2-0.35% | 0.35-0.6% | 0.6-0.8% | >0.8% |
| 行业ETF(A股) | <0.3% | 0.3-0.5% | 0.5-0.7% | 0.7-1.0% | >1.0% |
| QDII ETF | <0.5% | 0.5-0.7% | 0.7-1.0% | 1.0-1.5% | >1.5% |
| 商品ETF | <0.3% | 0.3-0.5% | 0.5-0.8% | 0.8-1.0% | >1.0% |
| 港股ETF | <0.1% | 0.1-0.3% | 0.3-0.5% | 0.5-0.8% | >0.8% |
| 美股ETF | <0.05% | 0.05-0.1% | 0.1-0.2% | 0.2-0.5% | >0.5% |

### 2.3 费率竞争格局（A股 ETF 费率战）

2023年以来，A股ETF费率战持续升级：
- 多家基金公司将宽基ETF费率降至 **管理0.15%+托管0.05%=0.20%**
- 部分甚至降至 **0.15%+0.05%=0.20%** 以争夺份额
- 选择同类ETF时，**低费率是显著优势**（长期复利差异）

**费率差异长期影响示例**：
- 假设两只跟踪相同指数的ETF，年化收益10%
- ETF A 费率0.2%，ETF B 费率0.8%
- 20年后：100万本金 → A: 639万 / B: 588万 → 差距51万（8%）

## 三、规模与流动性评估

### 3.1 基金规模

| 规模（亿元） | 评级 | 风险提示 |
|-------------|------|---------|
| >500 | 旗舰级 | 流动性极佳，跟踪误差低 |
| 100-500 | 大型 | 优秀，无需担忧 |
| 30-100 | 中型 | 良好 |
| 10-30 | 小型 | 关注流动性 |
| 2-10 | 迷你 | 流动性可能不足 |
| <2 | 🔴 微型 | **清盘风险高**，一票否决 |

**清盘条件**（触发任一即有风险）：
- 连续60个工作日基金资产净值低于5000万元
- 连续60个工作日基金份额持有人数量不满200人

### 3.2 日均成交额

| 日均成交额（万元） | 评级 | 影响 |
|------------------|------|------|
| >10000（1亿） | 极佳 | 大额买卖无冲击 |
| 3000-10000 | 良好 | 百万级别交易无压力 |
| 1000-3000 | 可接受 | 几十万以内无明显冲击 |
| 500-1000 | 偏低 | 大额交易需分批 |
| <500 | 🔴 不足 | **一票否决**，买卖困难 |

### 3.3 买卖价差（Bid-Ask Spread）

| 价差 | 评级 | 说明 |
|------|------|------|
| <0.05% | 极窄 | 顶级流动性 |
| 0.05-0.1% | 窄 | 优秀 |
| 0.1-0.3% | 适中 | 可接受 |
| 0.3-0.5% | 偏宽 | 隐性成本较高 |
| >0.5% | 宽 | 每次交易即亏0.5%+ |

### 3.4 做市商质量

**评估维度**：
- 做市商数量（>3家为佳）
- 做市商报价连续性（是否经常断档）
- 做市商承诺的最大价差
- 做市商为主流券商/做市机构

## 五、运营质量综合评分细则

### 评分表（模块三总分100分）

| 子项 | 分值 | 评分依据 |
|------|------|---------|
| 跟踪误差 | 30分 | 见1.2评判标准 |
| 费率水平 | 25分 | 与同类对比的相对位置 |
| 规模与流动性 | 30分 | 规模15分+成交额10分+价差5分 |
| 基金公司信誉 | 15分 | 见4.2评分维度 |

### 加分项

| 情况 | 加分 |
|------|------|
| 同类ETF中跟踪误差最低 | +3 |
| 同类ETF中费率最低 | +3 |
| 基金规模>100亿且持续增长 | +2 |
| 做市商≥5家 | +2 |

### 扣分项

| 情况 | 扣分 |
|------|------|
| 近1年跟踪误差扩大（较前年+50%以上） | -5 |
| 基金规模连续3季度缩水>20% | -5 |
| 基金公司有ETF清盘历史 | -3 |
| 做市商曾退出/更换 | -2 |
| 费率高于同类均值2倍 | -5（且触发一票否决） |

# 决策规则速查 — 《股票操盘宝典》

| 能力 | 一句话规则 |
|---|---|
| 市况定位：周期轮回与牛熊震荡判定 | 先用地量/量价/均线/KDJ判定现处牛/熊/震荡哪一市况，市况决定后面一切策略。 |
| 选股：大牛股必要条件与选股四要素 | 用「题材引领时代+流通盘小+启动时业绩平庸后续走强」+选股四要素(盘小/优质/有庄/在买点上)做准入闸门。 |
| 技术买卖点判定：MACD/KDJ/DMI | 先用DMI/ADX判断单边还是震荡，单边才用MACD/KDJ找买卖点，震荡市停用技术指标持币观望。 |
| 风险控制与资金管理 | 交易错误几乎都源于贪婪；用仓位上限+止损+盈利转出+年度纪律把风险敞口收敛，把利润取出来才算真赚。 |
| 择时 vs 择股 分工框架 | 择时解决"干不干"(风控)，择股解决"买哪只买多少"(收益)，先归因亏损来源再对症改。 |
| 定思维：9类操作思维矩阵 | 先定操作思维(长/中/短线 × 轻/中/重仓=9类)再定动作；市况决定思维类别，不混用。 |
| 股市二元论决策 | 面对对立项(买/卖、持股/持币、贪/惧、进/不进)先选当前市况更优一极，再据此动作。 |
| 静态+动态操作系统 | 系统须满足完备性(覆盖每交易日)+对应性(买信号必有对应卖信号)，静态定纪律、动态应市况，非买卖点不操作。 |
| 缠论式结构判定与三类买卖点 | 用完全分类把K线离散化为分型/笔/线段/中枢，定义一买二买三买与卖点，非买卖点不操作。 |
| 右侧确认进场 | 见底/顶分型不立即交易，等分型被次日K线(中阳线)确认成立再进，过滤假信号、提高胜率。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。

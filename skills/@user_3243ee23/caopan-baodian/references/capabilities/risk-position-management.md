## R — 原文 (Reading)

> 过了一个月回头一看，很多股票涨得非常好，于是再也坐不住了。立即加重仓位，甚至满仓。接下来股市一调整，就止损。导致后来的大行情主升浪没有胆量和勇气去抓。
> 有一种极大的侥幸心理，幻想股市会"再涨一波，做完这波就走"，认为"国家不会让股市这么快下跌的"，也有"再赚10%我就走"的……这一切体现了"分析和干是两码事"。
>
> — 胡斐，《股票操盘宝典》第四章"相信系统 + 资金管理与风险控制"

## I — 方法论骨架 (Interpretation)

本书最核心的风控主张：**交易错误几乎都源于贪婪，恐惧最多让你踏空或少赚，贪婪才是毁灭之源。** 因此风控的第一任务是"克制贪婪"，把贪婪用硬纪律约束住，而不是靠心态。

具体化为"一个前提 + 五大要素"：
- **一个前提**: 永远不贪（贪是万错之源）。
- **五大要素**: 不满仓重仓、分散组合、精准择时、不一根筋、下午买。
- **仓位上限**: 牛市不超过 80%、震荡平衡市不超过 40%、熊市空仓或 20% 以内；永不満仓，重仓最高到 70%。
- **资金管理节奏**: 把利润取出来才算真赚（盈利后取出一部分）、年度任务封闭（达标停工休息）、正金字塔建仓（大级别买点重仓、边涨边减）。
- **止损与纪律**: 防止反复止损；现金流不与情绪捆绑；不做变形交易（报复、扳本、杠杆受控、频繁交易）。

一句话：**贪 = 万错之源；用"仓位上限 + 盈利转出 + 年度纪律 + 止损"把敞口锁死，把赚到的钱取出来，才不会在下次回调中把利润和人一起洗掉。**

## A1 — 书中的应用 (Past Application)

### 案例 1: 倒金字塔建仓错过主升浪
- **问题**: 为什么很多散户行情里反而错过主升浪？
- **方法论的使用**: 用"建仓仓位管理"原则剖析。
- **结论**: 起步轻仓、涨高后满仓、一调整就止损 = 倒金字塔建仓，违反正金字塔。
- **结果**: 主升浪来临时没胆量也没仓位去抓（C17）——风控差导致收益归零。

### 案例 2: 头部侥幸心理看对做错
- **问题**: 为什么判断对了却做不对（没离场）？
- **方法论的使用**: 用"贪婪/侥幸心理"分析顶部行为。
- **结论**: 幻想"做完这波就走/国家不会让跌"，被贪婪拖着不肯空仓。
- **结果**: 被暴跌击垮、心态失衡（C18）——这正是"分析和干是两码事"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 赚了一波后上头，想**追加/满仓**博一把。
2. 亏损了不甘心想**扳本/加仓摊平**。
3. 纠结**赚了要不要落袋**、怎么管理盈利。
4. 想问**该怎么控制仓位/设置止损**。
5. 连续小亏后，想弄明白自己是不是在犯错。

### 语言信号 (用户的话里出现这些就应激活)

- "我该加仓吗 / 要不要满仓？"
- "亏了不少，要不要扳回来？"
- "赚了要不要卖 / 怎么落袋？"
- "怎么控制仓位 / 止损设在哪？"
- "我是不是太贪了？"
- "Should I go all-in / how do I manage risk?"

### 与相邻 skill 的区分

- 与 `market-phase-detection` 的区别：这里管**仓位与风险敞口**；市况判**牛熊**。仓位上限会随市况变化（牛 80%/震荡 40%/熊 20%），但职责不同。
- 与 `buy-sell-points` 的区别：这里管**下多重、何时降低风险**；买卖点管**何时进出**。
- 与 `decision-paradox` 的区别：这里的"贪/惧"是风控纪律；二元论是更广的买/卖、持股/持币决策框架。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **先归因：是贪婪不是市场**
   - 完成标准: 识别用户当前的冲动是否由贪（追高/满仓/扳本/入戏太深）触发；若是，先点明"贪是万错之源"。
   - 判停条件: 若判定进入"加杠杆/借钱/满仓"的激进操作，立即强烈提醒违规并停止给激进建议。

2. **套仓位上限**
   - 完成标准: 依据当前市况给出明确仓位上限（牛≤80% 参考 / 震荡≤40% / 熊≤20% 或空仓），并核对用户现仓是否超限。

3. **落资金纪律（取利 + 达标停工）**
   - 完成标准: 提醒"把利润取出来才算真赚"，设定盈利转出与年度任务封闭的触发点，防止回吐。

4. **给出止损与心态护栏**
   - 完成标准: 明确该票的止损纪律（防止反复止损）、防变形交易（不做扳本/报复/频繁交易），输出可执行的护栏清单。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要的是**交易系统的完整建立**（那是 `trading-system`）。
- 讨论**具体股票买卖时机**（那是 `buy-sell-points`）。
- **投资建议合规**相关权限之外的个人化具体仓位数字——给出原则与参考上限，不给绝对保证。

### 作者在书中警告的失败模式

- 贪婪致"买在卖点、卖在买点"（ce02）、高位想做长线低位想做短线（ce03）。
- 扳本心理导致报复性交易（ce09）、重仓单只被情绪绑架（ce14）。
- 用"心态不好"掩盖认知不足（ce15）、多动症式高抛低吸做飞（ce16）。
- 死多头/死空头为持仓辩护（ce18）。

### 作者的盲点 / 时代局限

- 仓位数字（牛 80%/熊 20% 等）基于个人经验与 2016 年前 A 股波动，现代注册制/量化市场波动结构不同，只能作参考而非铁律。
- "永远不贪"是理想化要求，实操需靠系统与人工复检克制——作者也承认"操盘=动态犯错+改错"。

### 容易混淆的邻近方法论

- 与纯"止损技术"不同，本书强调贪这一心理源头 + 仓位 + 取利节奏的**系统性风控**，而非单一止损点位。

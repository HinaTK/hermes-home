## R — 原文 (Reading)

> 我以2014年6月至2015年11月上证指数周K线图来说明这个年内的波段。2014年6月地量见底，随后行情经过放量、突破、盘升，过完春节开始飞涨，然后就是暴跌，2015年6月开始的股灾，随后震荡了一个多月，到8月18日开始轮跌，形成第二次股灾。
> 2015年9月底，沪市成交额已经缩到1500亿元，而年初在5000点高位时沪市成交量是13000多亿元，几乎缩到了1/10的水平，股市于是开始孕育一波比较可观的行情。
>
> — 胡斐，《股票操盘宝典》第一章"判大势"

---

## I — 方法论骨架 (Interpretation)

本书的核心主张：中国 A 股不是随机波动，而是会重复上演一段"年内周期轮回"。这段轮回有可辨认的九段：地量 → 放量或暴跌 → 突破 → 盘升 → 飞涨 → 暴跌 → 震荡 → 轮跌 → 地量。判定"现在处于轮回的哪一段"，就决定了当前该用什么态度面对市场。

判定市况时，本书综合用量价（成交量是否缩到前期高点的 1/3 以下 = 地量）＋均线（是否跌破/站上关键均线）＋周期级别（日/周/月线下的位置）多维度交叉确认。它特别强调"地量"是见底的最强信号，因为缩量代表卖压衰竭。

一句话：**交易之前先定位市况——你现在身处牛市、熊市、还是震荡市，这一段轮回走到哪一步，再谈具体做什么。**

## A1 — 书中的应用 (Past Application)

### 案例 1: 2014-2015 年完整轮回复现
- **问题**: 如何用一段真实行情看懂"周期轮回"？
- **方法论的使用**: 用上证周线把 2014 年 6 月～2015 年 11 月的走势对号入座到九段轮回。
- **结论**: 地量见底 → 放量突破 → 盘升 → 飞涨 → 暴跌（2015.6 股灾）→ 震荡 → 轮跌（8.18 二次股灾）→ 重回地量。
- **结果**: 与轮回规律完全吻合，验证了年内循环的可复现性。

### 案例 2: 2015 年 9 月地量见底
- **问题**: 股灾后要不要抄底？
- **方法论的使用**: 看沪市成交量缩到 1500 亿、约前期峰值 1/10，判定进入"地量"段。
- **结论**: 卖压衰竭、孕育新行情。
- **结果**: 2015 年 9 月底后确实启动一波可观的反弹，验证量价经验。

### 案例 3: 新疆德隆逆周期覆没
- **问题**: 如何理解"顺势周期"的重要性？
- **方法论的使用**: 用顺逆牛熊周期的对比说明。
- **结论**: 德隆 2002-2003 满仓甚至拉升，违背跨年周期。
- **结果**: 2004 年资金链断裂全军覆没——不懂周期、逆势满仓的代价。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想进场但不确定现在是牛市还是熊市、该不该买。
2. 大盘连续下跌后，在纠结"会不会到底/要不要抄底"。
3. 一段上涨后很嗨，在犹豫"要不要追/会不会见顶"。
4. 讨论 A 股为什么总是"跌了又涨、涨了又跌"，想找规律。
5. 制定月度/季度策略前，想先给市场定个性。

### 语言信号 (用户的话里出现这些就应激活)

- "现在是什么市况 / 现在是牛市还是熊市？"
- "现在算到底了吗 / 能不能抄底？"
- "大盘现在处于什么阶段 / 会不会见顶？"
- "地量是什么意思 / 怎么判断见底？"
- "买了会不会套 / 该不该现在就进场？"
- "What's the current market phase / Is this a bull or bear market?"

### 与相邻 skill 的区分

- 与 `stock-selection` 的区别：这里定位**大盘市况**；选股是选**具体个股**。市况是选股的先决条件。
- 与 `buy-sell-points` 的区别：这里给**宏观定性**（牛/熊/震荡）；买卖点是**精确进出场位置**。
- 与 `timing-vs-selection` 的区别：这里做市况判定本身；择时择股是责任分工原则。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **收集当前市场量价信号**
   - 完成标准: 拿到近期成交量（与前期高点对比）、大盘指数相对关键均线（20/30/60日内）、涨跌结构（普涨/分化/普跌）。

2. **用"地量"信号判定是否见底**
   - 完成标准: 判断成交量是否缩到前期最高量的 1/3 以下（地量=卖压衰竭的强见底信号）。
   - 判停条件: 若已是明显飞涨段的放量逼空，则直接跳到步骤 4 提示"追高风险"。

3. **对号入座到九段轮回**
   - 完成标准: 把当前特征归入 地量→放量/暴跌→突破→盘升→飞涨→暴跌→震荡→轮跌 中的一段，并明确指出阶段。

4. **给出市况定性 + 应对倾向**
   - 完成标准: 输出明确的"牛市 / 熊市 / 震荡市 + 当前所处轮回段"，并给出对应的大类倾向（牛市持股、熊市持币等待、震荡市波段）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要**预测未来某一天的具体点位/拐点**时——本书明确"定性不定量"，给的是阶段判断而非精确预测。
- 讨论**具体板块轮动/个股**选择时——那是选股与买卖点 skill 的领域。
- 用户身处**美股/港股**等非 A 股市场——书中"周期轮回"基于中国 A 股特征总结，未必适用。

### 作者在书中警告的失败模式

- 在"飞涨"段追高、在"暴跌/轮跌"段硬扛不止损——违反顺势周期。
- 被贪婪冲昏在头部"做完这波就走/再赚10%"，不肯离场（案例 C18）。
- 逆周期满仓（如新疆德隆），把资金链拖垮。

### 作者的盲点 / 时代局限

- 书成于 2015-2016 股灾后，其"周期轮回"是对 2014-2015 杠杆牛与三波股灾的经验归纳；注册制、机构化、量化主导的现代 A 股生态下，轮回形态与节奏可能改变。
- "地量 1/3、次新股必牛"等有量化依据但基于历史样本，非保证未来复现。

### 容易混淆的邻近方法论

- 与"股市推背图/年尾数字看牛熊"极易混淆——那种把天干地支、尾数 6/7/9 当预测工具的用法，本书也承认"定性非定量、不能确定拐点"，**不要当成可靠预测工具输出**，只作背景提法。

## R — 原文 (Reading)

> 从吉峰农机(300022)的走势我们可以看出，上涨的连续性并不如意。波段操作可能比较适合。
> 前期疯狂过的，未来也可能更加疯狂……从华谊兄弟(300027)2012年至2015年12月的周线图我们可以看出，该股第一波疯狂完之后，又以相似的形态疯狂了第二波。

> — 胡斐，《股票操盘宝典》第二章"入牛股"

## I — 方法论骨架 (Interpretation)

本书的核心主张：**超额收益主要靠选股**，不是靠频繁交易。选股不是为了"现在买一只涨的"，而是为了建立一套能持续跑出牛股的筛选流程。

选股没有一劳永逸的公式，但有方向性必要条件。作者反复强调"大牛股的必要条件"——通常是"题材引领时代 + 流通盘小 + 启动时业绩平庸但后续走强"；对整个市场又归纳出"选股四要素"（盘小、优质、有庄、在买点上）。同时作者点出两类可以重点关注的形态：**前期疯狂过的股票可能再疯狂一轮**、**从未炒作过的低位股可能突然启动成大牛股**（黑马），并强调要按股票类型（题材/次新/创业板/大盘蓝筹/周期股/现金牛）用不同视角去筛。

一句话：**选股是平时积累、反复熟悉的"内功"——用必要条件做准入闸门，先建自选池，行情来时才能信手拈来，而不是临时凭感觉抓一只。**

## A1 — 书中的应用 (Past Application)

### 案例 1: 华谊兄弟两轮相似疯狂
- **问题**: 什么样的股票值得跟踪？
- **方法论的使用**: 用"前期疯狂过的还会再疯狂"的形态观察周线。
- **结论**: 第一波疯狂后，又以相似形态走了第二波。
- **结果**: 可作为反复关注的选股标的。

### 案例 2: 立恩辰五年低迷后成黑马
- **问题**: 从未炒过的低位股能不能碰？
- **方法论的使用**: 用"未炒作标的可能突然启动"的思路看月线。
- **结论**: 前五年低迷，2014 年开始活跃后迅速变牛。
- **结果**: 验证"挖掘潜伏未炒作标的"的选股思路有价值。

### 案例 3: 中煤能源长期低迷
- **问题**: 周期股要不要重仓？
- **方法论的使用**: 分类看待——判断其受宏观+行业景气双重周期制约。
- **结论**: 上市以来长期低迷、业绩亏损，难以走持续行情。
- **结果**: 提醒避开深陷周期股，认识大周期的风险。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想进股市但不知道**哪一类股票值得关注/怎么选**。
2. 手里有一只自认为不错的票，想判断它够不够格进自选池。
3. 想建立自己的**自选股池/逆向分类**（题材、次新、创业板、蓝筹、周期、现金牛）。
4. 问"怎么选出像样的牛股 / 凭什么判断它会不会走牛"。
5. 纠结要不要跟风某只热点，想用必要条件冷静把关。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么选股 / 怎么挑股票？"
- "这只票值不值得关注 / 能不能买？"
- "怎么选出大牛股 / 牛股有什么特征？"
- "帮我建个自选池 / 我该关注哪些类型？"
- "这题材是不是炒过头了？"
- "How to pick stocks / Is this a good candidate?"

### 与相邻 skill 的区分

- 与 `market-phase-detection` 的区别：这里选**具体标的**；市况判**大盘阶段**。市况是选股的环境前提。
- 与 `buy-sell-points` 的区别：这里解决**选什么**；买卖点解决**何时进/出**。
- 与 `timing-vs-selection` 的区别：这里聚焦"择股"怎么做本身，不谈择时分工原理。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **按类型分类候选标的**
   - 完成标准: 明确该标的分属：题材股/次新股/创业板/中小盘/大盘蓝筹/周期股/现金牛股，明确其所属类别。

2. **用"大牛股必要条件"做准入闸门**
   - 完成标准: 逐条核对是否满足——题材是否引领时代、流通盘是否偏小、启动时业绩是否平庸（后续可能走强），并记录结论。
   - 判停条件: 若三项必要条件基本都不满足（机构大盘股、周期顶部、无题材），则提示"不适合作为牛股候选"，转到风险提示不再硬揽。

3. **用"选股四要素"复核**
   - 完成标准: 核对 盘小/优质/有庄/在买点上 四要素，明确哪几条成立、哪几条需后续确认。

4. **建立或更新自选池**
   - 完成标准: 给出该标的"进池/观望/剔除"的建议，并说明关注的价格区间（结合买点）与需要跟踪的确认信号。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要**确定性的个股预测**（"这只股下周一定涨吗"）——选股给必要条件与概率偏好，不给保证。
- 需要**具体买卖时机**时——那由 `buy-sell-points` 处理。
- 面对**已注册制、机构化/量化主导市场**中的纯大盘核心资产时——本书"题材+小盘+有庄"逻辑对核心蓝筹未必适用。

### 作者在书中警告的失败模式

- 选股不准导致频繁止损、频繁换股（ce13），越换越差。
- 倒金字塔建仓、行情起步轻仓、涨高才追——错过主升浪（C17）。
- 追热点演变成追涨杀跌（ce04/ce05）。
- 迷信"低市盈率好公司"而在 A 股熊市死拿四年一无所获（C05）——A 股重题材与周期，不能只看基本面。

### 作者的盲点 / 时代局限

- "次新股必牛/题材必炒"部分基于 2014-2015 注册制前的高波动生态；注册制扩容与退市常态化后，小盘题材逻辑在弱化。
- "有庄/主力"叙事建立在庄股时代，机构化+量化主导后该前提衰减。

### 容易混淆的邻近方法论

- 与"价值投资/长期持有好公司"思路不同——本书强调 A 股要重题材、择时、波段，而非单纯长期持有基本面票。

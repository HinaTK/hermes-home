## 1. 结构 (Structural)

### 类型
股票交易行动手册 / 操盘方法论（判势 — 选股 — 策略 — 系统 — 指标的全流程实战指南）

### 一句话主旨
建立一套"判大势 → 选牛股 → 定思维 → 信系统 → 用指标"的中国 A 股完整交易操作系统，让读者能按固定的、可复用的流程做买入卖出决策。

### 骨架 (主要论点及其关系)

1. **判大势 / 周期规律（第一章）** — A 股年内与跨年度有可复现的周期循环（地量→放量/暴跌→突破→盘升→飞涨→暴跌→震荡→轮跌→地量），并给出"股市推背图"定位所处阶段。
2. **入牛股 / 选股（第二章）** — 超额收益靠选股；给出超级大牛股、题材股、中小盘、创业板、妖股等的选股必要条件与一套选股流程。
3. **定思维 / 操作策略（第三章）** — 不同市况（牛/熊/震荡/短线）对应不同策略，不混用思维；核心是"择时解决干不干"。
4. **相信系统 / 操作系统（第四章）** — 股市二元论（牛市/熊市、持股/持币、贪婪/恐惧等对立的抉择原则）；静态+动态操作系统、资金管理与风险控制。
5. **最准指标（第五章）** — 以 MACD / KDJ / DMI 为主要买卖点指标，把进出场时点固化为"买点卖点"和条件反射。

**论点之间的关系**: 层层深入、递进式系统（判势 → 选股 → 策略 → 系统 → 指标），最终整合为一套完整交易操作系统。

### 作者要解决的核心问题
"普通股民为什么总亏钱？如何依靠一套可复制、可执行的中国 A 股操作系统稳定获利的超额收益，同时控制风险？"

## 2. 解释 (Interpretive)

### 关键术语 (作者本人的用法)

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 择时 | 判断"干不干"的问题，是决定是否行动、何时行动的开关，负责风控 | 非单纯选买卖点，而是整个"是否进场"的开关；作者称"择时解决干不干" |
| 择股 | 操作"哪只、多少"的问题，负责收益 | 与常识的"选股"几乎一致，但作者强调"选股是为了不选股"（平时勤练、战时信手拈来） |
| 地量 | 成交量缩到前期最高点成交额的 1/3 以下 | 有明确量化阈值，非普通"缩量" |
| 股市推背图 | 用天干地支/尾数规则对 A 股 60 年大周期的定性推演（如尾数 6、7、9 为牛市年份） | 非现代计量预测，是作者的经验性周期归类 |
| 买点/卖点 | 基于 MACD / KDJ 等技术指标定义的具体进出场位置，形成条件反射 | 特指数化、可重复判断的固位点，而非"感觉" |
| 图形定式 | 把最复杂买卖点固化成特定 K 线图形形态，形成条件反射 | 强调"图形 → 动作"的反射链条 |
| 股市二元论 | 从牛市/熊市、持股/持币等对立项中选出该市况下更优的一极 | 不是哲学二元论，是"二选一决策框架" |

### 核心命题 (用自己的话)

1. 中国 A 股有独特规律，不能照搬国外股市／大师名言，否则吃大亏。
2. 周期规律是核心战略判断；先定位市况（牛/熊/震荡），再谈具体操作。
3. 超额收益主要靠选股，风控主要靠择时；两者作用不同、不可混淆。
4. 选股是"内功"，平时大量熟悉股票，行情来时才能信手拈来。
5. 大牛股的必要条件：题材引领时代、流通盘小、启动时业绩平庸但后续走强。
6. 牛市的策略是"满仓持股、拿住不动"，熊市是"轻仓持币、等待"；不同市况要用不同思维。
7. 时间周期与规模不同，决策框架不同（牛市换股、熊市止损；大资金重选股、小资金可择时）。
8. 交易错误 99% 来自贪婪而非恐惧；贪婪才是毁灭之源。
9. "操盘 = 动态犯错 + 改错"；知是最重要的，不要用"心态不好"掩盖认知不足。
10. 技术分析不必事前 100% 准确，错误率再高也能通过组合和胜算逐步提高收益。

### 论证链
作者以"中国 A 股是独特的轮回波动游戏"为前提 → 先给出宏观周期规律（定市况）→ 再在既定市况下用对应选股法与策略（定动作）→ 用静态+动态系统与资金管理把动作约束住（定规则）→ 用 MACD/KDJ 等技术指标精确定位买卖点（定出入场）→ 最终"条件反射"式执行。证据主要来自 25 年沪深市场历史、具体年份实例（2014-2015 牛市股灾等）和个人交易经验，属经验实证+归纳。

## 3. 批判 (Critical) ★

### 作者的时代局限
- 书成于 2015-2016 年，基于 2014-2015 杠杆牛及三次股灾经验；此后 A 股生态（注册制、退市常态化、量化资金、北向资金）已大幅改变，早年"坐庄 / 题材炒作"逻辑可能弱化。
- "尾数 6、7、9 为牛年"等周期推演无法证伪、缺乏可重复的统计验证，难以作为可靠的未来预测工具。

### 作者的立场盲点
- 作者是强技术分析派 + 经验派，对基本面量化、指数化投资、长期持有被动策略几乎不讨论。
- 全书默认读者有大量盯盘时间与较频繁交易心态，对忙碌的业余投资者可能不友好。
- 把大量结论建立在"庄家""主力"叙事上，而现代机构化、散户占比下降的趋势下该前提在减弱。

### 未被证明的假设
- 假设周期规律会持续重演（"历史会重演"未加严格证明）。
- 假设多数读者能克服情绪、严格执行系统（"条件反射"理想化）。
- 假设技术指标在周/月线上不可骗线，从而比日线更可信（无实证）。

### 最强反对意见
"本书大部分是幸存者偏差 + 事后归因的叙事技术分析。A 股生态已变，任何依赖特殊周期、庄家行为与盘感的系统都难以在注册制、机构化、量化主导的市场稳定复制，且作者无法提供可重复验证的胜率数据。"
